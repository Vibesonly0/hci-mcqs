Quick revision notes

Short definitions to review before an exam.

Core terms

  • Operating System (OS): manages hardware resources and provides services for programs and users.
  • Program: a file stored on disk. Process: a running instance of a program.
  • PID: process identifier assigned to a process.
  • Scheduling: choosing a process from the ready queue and assigning the CPU.
  • Context switching: saving the current process state and transferring CPU control to another process.
  • System call: a request made by a user program for an OS service.
  • Interrupt: an event signal, often from hardware, that needs processor attention.
  • Trap: a software-generated exception or error as described in the lecture slides.
  • Long-term scheduler: controls which new processes enter the ready state.
  • Short-term scheduler: selects the next ready process to run on the CPU.
  • Medium-term scheduler: handles swapping/suspending processes between memory and secondary storage.
  • SRTF: runs the ready process with the shortest remaining CPU burst; a shorter arriving job can preempt the current one.
  • Segmentation: divides a program's logical address space into segments. Physical memory can hold segments in separate areas, with free spaces between them.
Tip: Say the definition in your own words, then give one real-life example. That is a strong way to prepare for viva questions.
